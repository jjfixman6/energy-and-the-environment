# SMR (NuScale) — 5-Minute Presentation Package

Optimized academic presentation on Small Modular Reactors, focusing on NuScale Power.

## Contents

- `presentation/slides.md` — Slide-by-slide structure with visual design specifications
- `presentation/script.md` — Full speaker script (~700 words, 5-minute delivery)
- `presentation/improvements.md` — Analysis of changes and where marks are gained
- `generate_pptx.py` — Python script to generate the PowerPoint file
- `SMR_NuScale_Presentation.pptx` — Generated presentation (dark theme, speaker notes embedded)

## Generate the PowerPoint

```bash
pip install -r requirements.txt
python generate_pptx.py
```
